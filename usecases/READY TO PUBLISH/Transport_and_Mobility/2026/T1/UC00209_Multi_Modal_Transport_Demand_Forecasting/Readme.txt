PROJECT TITLE
Multi-Modal Public Transport Demand Forecasting

PROJECT OVERVIEW
This project develops a multi-modal transport demand forecasting system capable of predicting passenger demand across multiple transport systems including buses, trains, trams and regional transport services. The project integrates real-world transport datasets from multiple cities and transport authorities to analyse temporal demand behaviour and forecast future transport usage trends.

The project addresses the limitation of traditional transport forecasting systems where transport modes are often analysed independently rather than as interconnected mobility systems.

OBJECTIVES
- Forecast passenger demand across transport modes
- Capture temporal and seasonal demand behaviour
- Support dynamic scheduling and transport planning
- Analyse transport demand trends across multiple cities
- Implement both machine learning and deep learning forecasting approaches

DATASETS USED
1. Transport for London (TfL) Journeys Dataset
2. NYC MTA Ridership Dataset
3. Melbourne Monthly Public Transport Patronage Dataset
4. Victorian Monthly Average Patronage by Day Type and Mode Dataset
5. NSW All-Modes Public Transport Patronage Dataset

TECHNOLOGIES USED
- Python
- Pandas
- NumPy
- Scikit-learn
- TensorFlow / Keras
- Matplotlib
- Jupyter Notebook

WORK COMPLETED
- Implemented API and CSV dataset loading pipeline
- Cleaned and standardised multiple transport datasets
- Developed unified multi-city transport demand schema
- Performed feature engineering including lag features and rolling averages
- Implemented Random Forest forecasting model
- Implemented LSTM deep learning forecasting model
- Performed hyperparameter tuning using time-series cross-validation
- Conducted model evaluation using MAE, RMSE and MAPE
- Developed visualisations for forecasting analysis
- Added high-demand classification support for dynamic scheduling

KEY FEATURES
- Multi-city forecasting
- Multi-modal transport analysis
- Time-series forecasting
- Machine learning and deep learning integration
- Dynamic scheduling support
- Real-world public transport datasets
