Introduction to Urban Retail Demand Forecasting



Retail demand forecasting plays an important role in modern business operations by helping organisations predict future customer purchasing behaviour using historical sales data. Accurate forecasting enables retailers to improve inventory planning, reduce operational waste, optimise logistics, and enhance customer satisfaction.

In urban retail environments, demand patterns can vary significantly due to population density, customer preferences, promotional activities, pricing strategies, and seasonal purchasing behaviour. As a result, businesses require intelligent forecasting systems capable of analysing historical transaction data and identifying complex demand trends over time.

This use case focuses on developing a retail demand forecasting workflow using machine learning and deep learning approaches. The project uses Australian retail sales transaction data containing product information, pricing details, customer behaviour, and order quantities. The workflow includes data preprocessing, exploratory data analysis, time-series preparation, feature engineering, and forecasting model development using Random Forest and LSTM Neural Networks.

The objective of this project is to demonstrate how predictive analytics and forecasting techniques can support smarter retail decision-making and improve operational efficiency in real-world business environments.

def adf_test(series):

    result = adfuller(series)

    labels = [
        'ADF Test Statistic',
        'p-value',
        '#Lags Used',
        'Number of Observations Used'
    ]

    for value, label in zip(result[:4], labels):
        print(f'{label}: {value}')

    if result[1] <= 0.05:
        print("\nStrong evidence against the null hypothesis.")
        print("The time series is stationary.")
    else:
        print("\nWeak evidence against the null hypothesis.")
        print("The time series is non-stationary.")

# Run test
adf_test(ts_data['Order Quantity'])
ADF Test Statistic: -19.77639989048792 p-value: 0.0 #Lags Used: 1 Number of Observations Used: 879 Strong evidence against the null hypothesis. The time series is stationary.
 
This section performs a stationarity test on the retail demand time-series data using the Augmented Dickey-Fuller (ADF) test. Stationarity is an important requirement in time-series forecasting because many forecasting models perform more effectively when the statistical properties of the data, such as mean and variance, remain stable over time. In this step, the adfuller() function from the statsmodels library is used to test whether the Order Quantity series is stationary or non-stationary. The null hypothesis (H0) assumes that the time series is non-stationary, while the alternative hypothesis (H1) assumes that the series is stationary. The results show an ADF test statistic of approximately -19.78 and a p-value below 0.05. Since the p-value is significantly smaller than the chosen significance level, the null hypothesis is rejected. This indicates strong statistical evidence that the retail demand time series is stationary. This section converts the daily retail demand data into weekly demand data to reduce short-term fluctuations and noise within the time-series dataset. Daily sales data often contains irregular variations caused by promotions, weekends, customer behaviour, and random purchasing activity, which can make forecasting patterns difficult to identify clearly. To improve trend visibility and create a smoother forecasting series, the Order Date column is first set as the dataset index using set_index(). The resample('W').sum() function is then used to aggregate the total order quantity for each week. This process groups all daily sales values within a week and calculates the weekly total demand. The resulting weekly demand plot shows a smoother and more stable demand pattern compared to the highly volatile daily demand graph. Reducing noise in the time series helps forecasting models better identify underlying demand trends, improves model stability, and supports more reliable machine learning and deep learning forecasting performance.

def create_sequences(data, window_size=WINDOW_SIZE):
    X, y = [], []
    for i in range(len(data) - window_size):
        X.append(data[i:i + window_size])
        y.append(data[i + window_size])
    return np.array(X), np.array(y)
