UC00209: Land Use Efficiency Analysis

Melbourne Open Data | Urban Planning | Data Analytics

Scenario

Melbourne consists of diverse land use zones including residential, commercial, and mixed-use areas. However, not all land is utilised with the same level of efficiency. Some areas are highly developed and support strong economic and population activity, while others remain underutilised.

This use case analyses land use efficiency by integrating multiple datasets from the City of Melbourne Open Data platform. The goal is to identify patterns in land utilisation and provide insights to support urban planning and decision-making.

Objective: Identify which Melbourne areas use land most efficiently by comparing total floor space, land area, and population data.

Datasets Used

CLUE Small Areas

Used to identify Melbourne regions and their land area.

Floor Space by Use

Used to calculate total built floor space in each region.

Resident Profiles

Used to incorporate population data into the land use analysis.

Methodology

  • Collected datasets from the City of Melbourne Open Data API.
  • Cleaned and standardised area names and numeric fields.
  • Aggregated total floor space by CLUE small area.
  • Merged land area, floor space, and population datasets.
  • Calculated land use efficiency using floor space divided by land area.
  • Created visualisations to compare high- and low-efficiency areas.

Core Efficiency Formula

efficiency = total_floor_space / total_land_area

Python Code Overview

Dataset Fetching Function

import pandas as pd import requests def fetch_dataset(dataset_id, limit=1000): url = f"https://data.melbourne.vic.gov.au/api/explore/v2.1/catalog/datasets/{dataset_id}/records" params = {"limit": limit} response = requests.get(url, params=params, timeout=60) response.raise_for_status() data = response.json() return pd.DataFrame(data.get("results", []))

Land Use Efficiency Calculation

merged_df["efficiency"] = ( merged_df["total_floor_space"] / merged_df["total_land_area"] )

Population Density and Smart Efficiency

merged_df["population_density"] = ( merged_df["population"] / merged_df["total_land_area"] ) merged_df["smart_efficiency"] = ( 0.6 * merged_df["efficiency"] + 0.4 * merged_df["population_density"] )

Key Findings

  • Melbourne CBD showed the highest land use efficiency due to dense built infrastructure.
  • Southbank and Docklands also demonstrated strong efficiency, reflecting high-density mixed-use development.
  • Some lower-efficiency areas may represent industrial zones, open spaces, or areas reserved for future development.
  • Land size alone does not determine efficiency; zoning, economic activity, and development intensity are also important.

Discussion

The analysis shows that land use efficiency is concentrated in central urban areas, particularly Melbourne CBD. This reflects the role of the CBD as a commercial and residential hub with significant vertical development. In contrast, areas with lower efficiency scores may not necessarily be poorly used, as they may support open space, industrial activity, transport infrastructure, or future development opportunities.

By including population data, the analysis provides a more complete view of how land is used by both infrastructure and people. This supports more informed planning decisions and highlights areas where further investigation may be useful.

Recommendations

  • Investigate low-efficiency areas to determine whether land is underutilised or intentionally reserved.
  • Monitor high-efficiency areas for infrastructure pressure and population demand.
  • Use efficiency indicators to support zoning, redevelopment, and urban planning decisions.
  • Extend future analysis using transport accessibility, business activity, and development approval data.

Limitations

This analysis depends on the availability and accuracy of open datasets. Population data was limited to 2016, while floor space data covers a broader time period. Therefore, results should be interpreted as analytical indicators rather than official planning measures.

Conclusion

This use case demonstrates how Melbourne Open Data can be used to analyse land use efficiency across different regions. By combining land area, floor space, and population data, the project provides useful insights into development intensity, urban density, and planning opportunities. The findings can support evidence-based decision-making for sustainable urban growth.
