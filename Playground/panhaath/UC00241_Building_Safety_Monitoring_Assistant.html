Building and infrastructure inspections are often performed periodically, which means early warning signs of structural problems may be missed. This use case demonstrates a data-driven safety monitoring assistant that combines structural sensor readings and inspection report text to identify possible building safety risks.

UC00241 - Building Safety Monitoring Assistant

This notebook demonstrates a working prototype of an AI-assisted building safety monitoring system. The system combines:

  • structural sensor readings
  • inspection report text
  • anomaly detection
  • risk scoring
  • maintenance recommendations

The prototype is designed as a client-facing proof of concept that shows how sensor data and inspection notes can be transformed into practical safety risk insights.

1. Use Case Goal

The goal is to identify possible safety risks in buildings or bridges earlier than a normal periodic inspection might.

The assistant looks for unusual sensor behaviour and risky inspection report language, then produces a risk level and suggested maintenance action.

Example output:

> Possible cause: structural fatigue

> Risk level: medium to high

> Recommended action: inspection within 48 hours

2. Data Collection and Loading

For this prototype, a simulated dataset is used. This is acceptable for demonstrating the system logic because the project focuses on the technical pipeline.

In a real deployment, the same code could be connected to live IoT sensors or public structural health monitoring datasets.

# Create a sample structural monitoring dataset

rng = np.random.default_rng(42)
timestamps = pd.date_range("2026-05-01 08:00", periods=160, freq="15min")

# Normal sensor behaviour
vibration = rng.normal(1.2, 0.25, len(timestamps))      # mm/s
tilt = rng.normal(0.08, 0.03, len(timestamps))          # degrees
crack_width = rng.normal(0.18, 0.04, len(timestamps))   # mm
temperature = rng.normal(21, 2, len(timestamps))        # Celsius
humidity = rng.normal(55, 6, len(timestamps))           # percentage

# Inject unusual behaviour to simulate safety risks
anomaly_idx_1 = np.arange(55, 68)
anomaly_idx_2 = np.arange(118, 128)

vibration[anomaly_idx_1] += rng.normal(2.8, 0.35, len(anomaly_idx_1))
tilt[anomaly_idx_1] += rng.normal(0.18, 0.04, len(anomaly_idx_1))

crack_width[anomaly_idx_2] += rng.normal(0.35, 0.06, len(anomaly_idx_2))
vibration[anomaly_idx_2] += rng.normal(1.5, 0.25, len(anomaly_idx_2))

# Simulated inspection report notes
reports = []
for i in range(len(timestamps)):
    if i in anomaly_idx_1:
        reports.append("Increased vibration observed near support beam. Possible fatigue or loose connection.")
    elif i in anomaly_idx_2:
        reports.append("Visible crack widening and minor spalling near concrete column. Further inspection recommended.")
    elif i % 37 == 0:
        reports.append("Minor corrosion stains noted, no immediate movement detected.")
    else:
        reports.append("Routine inspection: no major structural issues observed.")

df = pd.DataFrame({
    "timestamp": timestamps,
    "vibration_mm_s": vibration.round(3),
    "tilt_degree": tilt.round(3),
    "crack_width_mm": crack_width.round(3),
    "temperature_c": temperature.round(2),
    "humidity_pct": humidity.round(2),
    "inspection_report": reports
})

5. Anomaly Detection

The prototype uses Isolation Forest, an unsupervised anomaly detection method. This is suitable because real safety-monitoring systems may not always have labelled examples of every possible structural problem.

The model learns the normal pattern of the sensor readings and marks unusual points as anomalies.

sensor_features = [
    "vibration_mm_s",
    "tilt_degree",
    "crack_width_mm",
    "temperature_c",
    "humidity_pct"
]

X = df[sensor_features]

# Scale features so that one unit does not dominate the model
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# Train anomaly detector
model = IsolationForest(
    n_estimators=150,
    contamination=0.08,
    random_state=42
)

df["anomaly_label"] = model.fit_predict(X_scaled)
df["is_anomaly"] = df["anomaly_label"].map({1: 0, -1: 1})
df["anomaly_score"] = -model.decision_function(X_scaled)

6. Inspection Report Text Analysis

For a prototype version, a clear keyword-based text analysis method is enough.

The system searches for engineering risk terms such as crack, corrosion, fatigue, spalling, settlement, and water ingress. This makes the system explainable during stakeholder review.

risk_keywords = {
    "crack": 2,
    "cracking": 2,
    "widening": 2,
    "fatigue": 3,
    "corrosion": 2,
    "spalling": 2,
    "settlement": 3,
    "movement": 2,
    "loose connection": 2,
    "water ingress": 2,
    "deformation": 3
}

def text_risk_score(report):
    report_lower = report.lower()
    score = 0

    for keyword, weight in risk_keywords.items():
        if keyword in report_lower:
            score += weight

    return score

df["text_risk_score"] = df["inspection_report"].apply(text_risk_score)

7. Risk Assessment Construction

The final risk score combines:

  1. Sensor threshold score
  2. Machine-learning anomaly result
  3. Inspection report text risk score

This makes the assistant more useful than a simple graph because it converts raw data into a decision-support output.

def sensor_threshold_score(row):
    score = 0

    # These are simple demonstration thresholds.
    # In a real system, thresholds should come from engineering standards or expert advice.
    if row["vibration_mm_s"] > 3.0:
        score += 3
    elif row["vibration_mm_s"] > 2.0:
        score += 2
    elif row["vibration_mm_s"] > 1.5:
        score += 1

    if row["tilt_degree"] > 0.25:
        score += 3
    elif row["tilt_degree"] > 0.15:
        score += 2
    elif row["tilt_degree"] > 0.10:
        score += 1

    if row["crack_width_mm"] > 0.50:
        score += 3
    elif row["crack_width_mm"] > 0.35:
        score += 2
    elif row["crack_width_mm"] > 0.25:
        score += 1

    return score

def classify_risk(total_score):
    if total_score >= 8:
        return "High"
    elif total_score >= 4:
        return "Medium"
    else:
        return "Low"

df["sensor_threshold_score"] = df.apply(sensor_threshold_score, axis=1)

# Combine evidence into one explainable risk score
df["final_risk_score"] = (
    df["sensor_threshold_score"]
    + (df["is_anomaly"] * 3)
    + df["text_risk_score"]
)

df["risk_level"] = df["final_risk_score"].apply(classify_risk)

8. Maintenance Recommendation System

The assistant now converts the risk level into a clear recommendation.

def recommend_action(risk_level):
    if risk_level == "High":
        return "Urgent inspection within 24–48 hours. Increase monitoring and consider restricting access until checked."
    elif risk_level == "Medium":
        return "Schedule engineering inspection within 7 days and monitor the affected sensor readings more frequently."
    else:
        return "Continue routine monitoring and normal periodic inspection."

df["recommended_action"] = df["risk_level"].apply(recommend_action)

9. New Reading Demonstration Function

This function allows a new sensor reading and inspection note to be tested immediately.

This is useful in the stakeholder review because you can type in a new example and show that the assistant produces a risk assessment.

def analyse_new_reading(vibration_mm_s, tilt_degree, crack_width_mm, temperature_c, humidity_pct, inspection_report):
    new_data = pd.DataFrame([{
        "vibration_mm_s": vibration_mm_s,
        "tilt_degree": tilt_degree,
        "crack_width_mm": crack_width_mm,
        "temperature_c": temperature_c,
        "humidity_pct": humidity_pct
    }])

    new_scaled = scaler.transform(new_data[sensor_features])
    anomaly_prediction = model.predict(new_scaled)[0]
    is_anomaly = 1 if anomaly_prediction == -1 else 0

    temp_row = {
        "vibration_mm_s": vibration_mm_s,
        "tilt_degree": tilt_degree,
        "crack_width_mm": crack_width_mm
    }

    sensor_score = sensor_threshold_score(temp_row)
    text_score = text_risk_score(inspection_report)
    final_score = sensor_score + (is_anomaly * 3) + text_score
    risk_level = classify_risk(final_score)
    action = recommend_action(risk_level)

    result = {
        "vibration_mm_s": vibration_mm_s,
        "tilt_degree": tilt_degree,
        "crack_width_mm": crack_width_mm,
        "is_anomaly": is_anomaly,
        "text_risk_score": text_score,
        "final_risk_score": final_score,
        "risk_level": risk_level,
        "recommended_action": action
    }

    return pd.DataFrame([result])

analyse_new_reading(
    vibration_mm_s=4.2,

    crack_width_mm=0.54,
    temperature_c=22.0,
    humidity_pct=58.0,
    inspection_report="Increased vibration and crack widening. Possible fatigue near support beam."
